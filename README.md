# biom5350-seq-tools
\#Sequence utilities for BIOM5350

\#\#This repo is to test out using GitHub/git with example files of a python calculator for GC (and AT) content from a list of sequences (gc_content.py). It contains a file of sample sequences, example.fasta to test changes to the calculator. 
To test the calculator (i.e., after making changes to it), run this (after "\$&gt;):

\`\`\`\$&gt; python gc_content.py example.fasta

\#\#The most recent version of the script will output the %GC content, %AT content, and length for each sequence in the file, as well as a summary statement of total average %GC across all the sequences.
